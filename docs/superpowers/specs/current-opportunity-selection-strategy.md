# 当前机会挖掘选股策略说明

这份文档用产品语言说明当前机会挖掘模块怎样选股。它描述的是代码里正在生效的逻辑，不展开所有具体参数。

## 1. 模块目标

机会挖掘回答两个问题：

1. 今天或当前快照下，哪些 A 股值得进入观察列表。
2. 上一批已经挖掘出的标的，今天表现如何。

面板里的当日机会可以使用最新行情快照；正式历史候选和复盘结果仍以本地收盘数据落库为准。

## 2. 基础股票池

所有股票策略先经过统一股票池过滤，只保留有正常成交、交易状态可用、代码范围符合沪深 A 股习惯的标的。

基础过滤会排除几类不适合作为普通机会跟踪的股票：

- 北交所等非当前主筛选范围代码。
- ST 或名称带明显风险标记的股票。
- 一字板等无法正常反映盘中博弈的股票。
- 如果本地有市值和上市日期数据，会继续剔除过大市值或上市时间太短的标的。

这一步的作用是先控制噪音，让后面的策略主要面对可交易、可比较的常规股票。

## 3. 异动捕手

`momentum_breakout` 负责找“今天有明显异动”的股票。它现在主要有三类入选路径。

### 3.1 涨幅异动

这条路径寻找当天涨幅已经明显走强、但还没有进入过热或封死状态的股票。

它关注的是：

- 当天涨幅是否进入强势区间。
- 不同板块用不同的涨幅容忍范围。
- 最近一段时间是否已经有一定趋势基础。
- 成交额是否足够，避免流动性太弱的票。

适合理解为：已经走出来、还没有完全透支的强势异动。

### 3.2 上影线异动

这条路径寻找盘中明显冲高、收盘或最新价从高点回落，但还没有明显走弱的股票。

它关注的是：

- 最高价相对开盘价有明显上冲。
- 最高价相对收盘价或最新价留下明显上影。
- 最新涨跌幅不能跌破 `-3%` 走弱线；跌超 3% 的票会被剔除。
- 同样需要满足趋势基础和成交额要求。

这里的重点不是“只要有长上影就入选”，而是保留冲高回落但仍有观察价值的标的，过滤已经明显转弱的标的。

### 3.3 早强回落补充

这条路径用于补充近期已经出现过强势拉升、当天出现冲高回落或强势调整的股票。

它关注的是：

- 最近几天是否出现过足够强的单日异动。
- 当前是否留下较明显上影或调整痕迹。
- 成交额是否仍然活跃。
- 如果已经进入强势榜前列，会避免重复进入这条补充路径。

适合理解为：前面已经证明过强度，今天出现回落整理，仍值得观察但不和强势榜重复计数。

## 4. 强势榜

`rps_stock_top20` 负责找相对强度持续靠前的股票。

它不只看今天涨跌，而是比较最近一段时间的相对表现：

- 短周期相对强度要靠前。
- 中周期相对强度也要靠前。
- 综合强度越高，排序越靠前。

适合理解为：趋势持续性已经被市场排名验证的强势股。

## 5. 结果排序和展示

异动捕手更重视成交额和当日表现，优先展示成交更活跃、涨跌表现更强的标的。

强势榜更重视相对强度排名，优先展示短中期都强的标的。

面板展示时会把来源分成：

- `异动`：来自 `momentum_breakout`。
- `强势`：来自 `rps_stock_top20`。

异动标的还会带 `path`，用来说明它是通过涨幅、上影线、早强回落补充，还是多个路径共同入选。

## 6. 历史复盘边界

盘中或收盘后用最新行情临时筛出的结果只用于面板展示，不直接成为历史复盘样本。

正式历史候选来自收盘数据跑出的结果，并写入本地 `candidates` 表。后续复盘会围绕这些已经落库的候选计算次日和多日表现。

这个边界让面板可以及时展示今天的机会，同时保证历史统计基于稳定的收盘口径。
