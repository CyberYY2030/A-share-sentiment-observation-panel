## 0. 一句话：这玩意儿抓什么

> 抓**凯莱英 2026-06-18 那种一天**：一只票横了一两个月、波动越来越小、量越缩越干、均线挤成一团——突然某天放量拉出一根大阳,一举站上所有均线。这是资金进场的第一脚油门,后面往往就是主升浪。
>
> 系统每天收盘后把全市场符合这个画像的票列出来,**通常只有 4~6 只**。你只需要看这几只,判断题材、资金、消息值不值得跟——买卖点仍然你定。

## 1. 从样本图反推的形态画像（第一性原理）

对 11 张标注图逐一量化分析后,启动日的共同结构是四件事**同时发生**:

1. **前期低波动**：启动前 15 日日均振幅小,近 5 日量能 ≤ 40 日均量(缩量横盘,浮筹清干净);
2. **均线粘合**：MA5/10/20/50 挤在一个 ≤6~7% 的窄带里——这是"横盘够久"的数学形式;
3. **首次**：此前 10 日内没有出现过同级别大阳(不是趋势中段的第 N 根阳线);
4. **放量大阳穿线**：当日大阳(相对自身波动率够大)、收盘近全天最高、量能 ≥ 近5日均量 1.5 倍、**一根阳线从均线簇下方收到全部均线上方**。

关键设计决策:**"大涨"按个股自身波动率定义**——启动日涨幅 ≥ max(4.5%, 3×自身20日σ)。京东方、永辉这种大盘股 +4.5% 就是它们的启动(固定 6% 会错杀);高波动票 +6% 若只有 1.5σ 属普涨,会被正确挡掉。

## 3. 两条腿的分工（对应你定的两个能力)

- **能力① 初期异动早发现** = 本扫描器(平底首次放量启动,凯莱英型);
- **能力② 阶段最强势标的** = 现有回踩-再启动漏斗(趋势中段的平安/华友/方大型)。
- 闭环:启动日漏掉的票,涨起来后自然进强势漏斗,回踩再启动时第二次送到你面前。

## 4. 给 Codex 的实现细节（按需读）

**M1 新扫描器 `mining/scanners/launch_burst.py`**,`strategy_id="launch_burst"`,注册进扫描器框架:

对每只股票每个交易日 T(基于 `ash.kline_daily`,`sec_type='stock'`):
```
pct_t   = close/pre_close - 1        # 禁用 change_pct 列——库里大量 NULL(已实证)
sigma20 = std(pct, 20日).shift(1),下限 0.008
入选 = ①cluster: T-1 日 (max-min)/min of {MA5,MA10,MA20,MA50} ≤ p.ma_cluster_max(0.07)
      ②first:   前10日 max(pct) < p.first_sigma(2.5) × sigma20
      ③contract: 前5日均量 ≤ p.vol_contract(1.0) × 前40日均量
      ④big:     pct_t ≥ max(p.launch_min_pct(0.045), p.launch_sigma(3.0) × sigma20)
      ⑤strongclose: close>open 且 close/high ≥ p.close_strength(0.95)
      ⑥volx:    volume ≥ p.vol_expand(1.5) × 前5日均量
      ⑦reclaim: close > max(MA5,MA10,MA20,MA50)   # 一阳穿线
      ⑧liquid:  amount ≥ p.amount_min(2e8);价格 sanity(close<3000)防指数串码(000852 等已实证混入)
日内截断:按 (pct_t/sigma20)×量比 排序取 top p.daily_cap(10)——个别普涨日原始命中可到40+,必须截断
```
全部阈值进 params 一处集中。features_json 记录:pct、量比、sigma 倍数、cluster 宽度、run 前缩量比,供面板与复盘。

**M2 管线接入**
- 注册后 `run_daily.py` 自动跑;候选进 `candidates` 表 → `backfill_outcomes` 免费获得 t+1/t+2/t+5 前向追踪(Phase J 口径),上线即开始自证。
- `mining/watchlist.py::STRENGTH_SCANNERS` 加入 `"launch_burst"`(首次放量启动=强度印记,漏掉的票进漏斗等回踩)。

**M3 面板**
