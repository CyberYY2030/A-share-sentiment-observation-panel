# 筛选口径规格：强趋势 / 异动

本文件是**可移植的口径规格**，不是本仓库的实现说明。目的是把「什么算强趋势、什么算异动」这套定义完整交出去，供 A 股指标面板与机会挖掘模块复用。

> 2026-08-13 说明：文中的 `src/skills/` 与 `config/skills/` 是原始可移植规格的外部实现路径，本仓库不包含这些文件，不能作为本项目的代码入口。当前 A 股正式选股以 `docs/superpowers/specs/current-opportunity-selection-strategy.md` 和 `mining.capabilities.CAPABILITY_REGISTRY` 为准；本文件只保留设计原则与移植注意事项。

---

## 0. 三条贯穿性原则

这三条是整套口径的地基。移植时可以改参数、改因子，但改掉这三条就不再是同一套东西。

**① 闸门（gate）与排序（score）是两件事，不可互换。**
闸门是「是不是上升趋势」的**定义**，必须全部满足，不允许投票、不允许几选几。分数只决定闸门内的**名次**。
反面教材：旧版把「均线多头排列 / MA20 斜率 / ADX / 距 MA20 距离」做成「4 选 3」，结果 553 只里 226 只（40.9%）被标成 strong，其中 42% 根本不是多头排列、27% 近 60 日在跌——暴跌股反弹几天就能凑齐 3 票。**一个把 40% 标成「强」的榜单不是筛选器，是噪音。**

**② 「强」「异动」必须是横截面分位或自身分布的分位，不能是绝对阈值。**
绝对阈值在牛市放行一半的票、熊市一只都不放，这个词就不再携带信息。
- 强趋势：闸门内按分数取**前 20%**。
- 异动：先扣掉基准，再用**这只票自己的**残差波动率归一，取 ≥3σ。

**③ 「算不出来」必须和「没有发生」区分开，绝不能渲染成安静的正常。**
基准数据陈旧、历史不足、基准方差为零、分母为零——这些一律**跳过并记录原因**，不允许退化成默认值（beta=1.0、超额=绝对收益）继续算。**一个错的数字挂在对的标签下，比没有这个榜更糟。**

## 1. 强趋势（Strong Trend）

### 1.1 定义

> 强趋势 = 满足全部硬闸门 **且** 在当日闸门内相对强度排名前 20%。

三档标签：

| 标签 | 条件 |
|---|---|
| `strong` | 过闸门 **且** 在闸门内分数排名前 `strong_top_pct`（20%） |
| `developing` | 过闸门，但不在前 20% |
| `breaking_down` | 近 `breakdown_lookback_days`（60 日）内曾是 strong，**且**（MA20 斜率转负 **或** 收盘跌破 MA50） |
| `none` | 其余 |

### 1.2 闸门（全部必须满足）

| 条件 | 参数 | 为什么 |
|---|---|---|
| 均线多头排列 | `close > MA20 > MA50 > MA200` | 趋势的结构定义 |
| MA200 上行 | `MA200(今日) > MA200(20 个交易日前)` | 排除长期下降趋势中的反弹 |
| **方向确认** | `+DI > −DI` | **ADX 不带方向**，必须由 DMI 定向（见 1.5） |
| 可交易 | 20 日均成交额 ≥ 2000 万美元 | 排除流动性陷阱 |
| 历史充足 | ≥ 210 根 K 线 | 算得出 MA200 与 126 日相对收益 |
| 数据新鲜 | 最后一根 K 线日期 == 目标日期 | 陈旧个股不参与排名 |

### 1.3 分数（只在闸门内计算）

四个因子，**各自先在闸门内做横截面百分位排名**，再加权求和：

```
trend_score = 0.35 · pct_rank(rel_126d)
            + 0.35 · pct_rank(rel_63d)
            + 0.20 · pct_rank(path_quality)
            + 0.10 · pct_rank(pct_of_high)
```

| 因子 | 计算 | 含义 |
|---|---|---|
| `rel_126d` | `个股 126 日收益 − 基准 126 日收益` | 半年相对强度，趋势的主证据 |
| `rel_63d` | `个股 63 日收益 − 基准 63 日收益` | 季度相对强度，趋势是否还在延续 |
| `path_quality` | `63 日收益 ÷ 年化波动率`（年化波动率 = 近 63 日日收益标准差 × √252） | 这条趋势拿不拿得住。两只同样涨 40% 的票不等价，这个因子把「有序推进」和「靠 8% 日振幅晃上去」分开 |
| `pct_of_high` | `收盘价 ÷ 近 252 日最高价` | 距区间高点 |

**三个必须照抄的细节：**

1. **权重作用在百分位上，不是原始数值上。** 否则量纲互相压制——`rel_126d` 的 0.8 和 `path_quality` 的 3.2 直接加权是没有意义的。
2. **百分位和 20% 切点都只在闸门内取。** 若在全体股票上排名，未过闸门的票会重排过闸门的票的相对顺序（四个因子分别排名，四个百分位之和不是任何固定底层分数的单调函数）；而且在窄幅行情里，每个龙头的百分位都贴近 1.0，前 20% 的切点退化成噪音。
3. **「前 20%」是个数，不是阈值。** 用 `score >= quantile(0.8)` 会把并列在切点上的全放进来（三只分数都是 0.667、80 分位也是 0.667 → 三只全算 strong，而规则只允许一只）。正确做法：对闸门内按 `(分数降序, 代码升序)` 排序，取前 `ceil(n × 20%)`。**代码作为第二排序键**保证同一份数据永远给出同一个榜。

未过闸门的票 `trend_score` 记 **NULL**，不记 0——0 是一个「排在最底部」的真实分数，NULL 才是「不在这个排名体系内」。

### 1.4 基准（benchmark）

美股用 SPY。**基准必须满足与个股相同的新鲜度与复权要求**：

- 基准历史 < 127 根 K 线 → **整个扫描跳过**，不出榜。
- 基准最后一根 K 线不是目标日 → **整个扫描跳过**。理由：基准停更三天，意味着每只票都在和一个偏移三天的窗口相减，「超额收益」这个减法悄悄失去意义。
- **基准必须走和个股一样的拆股/除权调整。** 这是拆股破坏力最大的一处：每只票自己的收益仍然是对的，而从所有票里减掉的那个数是错的——**整个榜一起倾斜，而且看起来什么都没坏**。

**降级是禁止的。** 基准不可用时不允许退化成「用绝对收益代替超额收益」——榜上打的标签是「超额」，那样会把一个 beta 读数印在「超额」标签下，在上涨行情里几乎全书都「有趋势」。

### 1.5 为什么废掉 ADX 排序（移植时最重要的一条）

原系统按 ADX 排序，实测：

- `corr(ADX, 60 日涨跌幅) = 0.295`
- `corr(ADX, |60 日涨跌幅|) = 0.547`

**ADX 度量的是「趋势强度的绝对值」，不是「涨得强」。** PYPL 的 ADX 42.4 是**跌**出来的。方向信息在 ±DI 里，而排序完全没用到它。

结论：**ADX 可以留在闸门/展示里作为辅助，绝不能作为排序键。** 任何按 ADX、按波动率、按振幅排序的「强势榜」都会系统性地把暴跌股排到前面。

### 1.6 效果对照（真实数据，553 只美股）

| | 旧规则 | 新规则 |
|---|---|---|
| 过闸门 | —（4 选 3 投票） | 121 只 |
| 标记 strong | 226 只（40.9%） | 25 只（4.5%） |

## 2. 异动（Anomaly）

### 2.1 定义

> 异动 = 剔除市场/板块已经解释的部分之后，这只票**自己**的意外，且幅度达到它自己历史波动的 3 倍标准差以上。

一句话：**不是「波动大的票又波动了」。**

### 2.2 核心公式

对每只票，用它自己的**行业 ETF**作基准（没有则退回大盘 SPY）：

```
# 1. 用过去 252 个交易日的配对日收益估 beta
beta = Cov(r_stock, r_bench) / Var(r_bench)          # 两者都用 ddof=1

# 2. 历史残差序列与它的标准差
residual_hist = r_stock − beta · r_bench
residual_sigma = std(residual_hist, ddof=1)

# 3. 当日残差 z 分数 —— 这就是异动分数
residual_z = (r_today − beta · r_bench_today) / residual_sigma

# 4. 跳空残差 z（只用于打标签，不用于排序/定级）
gap        = 今开 / 昨收 − 1
bench_gap  = 基准今开 / 基准昨收 − 1
gap_residual_z = (gap − beta · bench_gap) / residual_sigma

# 5. 成交量 z —— 在对数空间算，只作确认
volume_z = (ln(今日成交量) − mean(ln(历史成交量))) / std(ln(历史成交量), ddof=1)
```

**必须照抄的数值细节：**
- `np.cov` 默认 `ddof=1`、`np.var` 默认 `ddof=0`，**混用会让 beta 偏高 n/(n−1)**，在 60 个观测的下限处是 1.7% 的系统性偏差。两处统一 `ddof=1`。
- 估计窗口**不包含当日**（`hist = slice(-(window+1), -1)`）。用当日数据估自己的 sigma 会自我稀释。
- 成交量走**对数**，因为成交量分布右偏严重，原始空间的 z 分数没有意义。

### 2.3 触发条件（三条同时满足）

| 条件 | 参数 |
|---|---|
| `abs(residual_z) ≥ 3.0` | `residual_z_min` |
| `volume_z ≥ 1.0` | `volume_z_min`——**成交量只作确认，不单独触发** |
| 当日成交额 ≥ 2000 万美元 | `dollar_volume_min` |

数据前置：历史 ≥ 180 根 K 线；与基准的**重叠**样本 ≥ 180；配对收益 ≥ 60 个；基准方差 > 0；残差 sigma > 0。任一不满足 → 跳过并计入 skip 原因，**不出现在榜上，也不算「今天平静」**。

### 2.4 严重度：只由幅度决定

```
3.0 ≤ |z| < 4.0  →  warning
4.0 ≤ |z| < 6.0  →  alert
6.0 ≤ |z|        →  critical
```

**绝不能按「触发器个数」升级。** 一次跳空必然带来放量和振幅放大——把三个互相关联的探测器当独立证据数，等于把一件事数了三遍。这是旧版把 CRCL、VST 这类票推上榜的直接原因。

### 2.5 排序键

**排序键 = `|residual_z|` 本身，没有任何额外权重。** 两个理由：

1. **榜上打印的就是这个 σ，排序必须能从打印出来的数字重建。** `+4.2σ` 排在 `+6.0σ` 前面，读者会认为榜坏了——**一个读者无法核对的顺序，正是这套筛选一开始要治的病。**
2. 曾经加过「惯犯惩罚」`score = |z| / (1 + 4 × 命中率)`，**实测无效**：残差已经按每只票自己的 sigma 归一，惯犯的高波动早就被除掉了。全库 553 只的命中率只在 0.0%–2.8% 之间（SMCI 这个典型的「天天异动」票和 AVGO、ELV 无法区分），惩罚系数上限 1.11，连续三天没改变过前 8 名。`chronic_rate` 保留在 metrics 里作诊断，不进排序。

### 2.6 描述标签（只影响展示，不参与定级）

按信息量从高到低排列，取第一个作为 `move_kind`：

| 标签 | 条件 |
|---|---|
| `gap` | `abs(gap_residual_z) ≥ 2.0` |
| `breakout_up` / `breakout_down` | 收盘价创 60 日新高/新低 |
| `range_expansion` | 当日振幅 / 20 日 ATR ≥ 2.0 |
| `volume_surge` | `volume_z ≥ 2.0`（高于 1.0 的最低确认线） |
| `intraday` | 以上都不满足时的兜底 |

**用收盘价残差意味着「跳空不回补」是自动检查的**：开盘跳 −10%、收盘只 −1.7% 的票，残差不达标，本来就不该进榜。这比单独写一条「跳空回补过滤」更省事也更严密。

### 2.7 板块共振：降级为纯上下文

旧版在个股和板块同向跳空时**升级** severity，方向是反的：**一个板块已经能解释的动作，携带的个股信息最少。** beta 调整已经把这部分从分数里扣掉了，共振字段只作阅读上下文：板块同向且板块自身涨跌幅 ≥1.5% 记 `strong`，否则 `weak`。

### 2.8 效果对照（真实数据）

旧口径当日产出 75 行 → 新口径 19 个事件。

## 3. 拆股 / 除权：两个榜共用的前置

`prices_daily` 存**未复权**原始价，所以 5:1 拆股读起来是 −80% 的一天。这一根 K 线会污染每一个跨过它的窗口：异动榜把它排成全书最大事件，强趋势榜在之后 126 个交易日里丢掉一个真正的龙头（半年收益读作 −80%）。反向拆股则反过来，把票顶到榜首。

**判定（三条同时满足才认定为拆股）：**

1. `abs(今开 / 昨收 − 1) × 100 ≥ 35%`
2. 当日振幅比 `(high − low) / close` ≤ 3 × 该股近 60 日振幅比中位数（**滞后一日**取，不含当日）
3. 隐含因子 `昨收 / 今开` 落在申报过的拆股比例上（2,3,4,…,100 及其倒数），容差 5%

**为什么需要第 2 条**：拆股改变价格水平但不改变当天的「性格」——按当日自身价格衡量，它的日内振幅是平常的，而真实的同等幅度大跌绝不会平常。这个判据是**尺度无关**的，正拆反拆同一条规则。

**为什么单靠第 2 条不够**：现金收购会把股价钉在成交价上，产生同样平静的振幅。所以还必须落在申报比例上。（这一条有专门的回归测试：「现金收购的平静大跳空不得被复权抹掉」。）

**复权因子取自开盘价**，它把当天真实的跳空吸收进拆股因子里——一天的跳空两种做法都无从知晓，而这样做两侧的每一个收益率都是对的。

## 4. A 股移植注记

以下是直接照搬会出错的地方，按风险从高到低排。

### 4.1 必须改的

| 项 | 美股 | A 股 |
|---|---|---|
| **复权** | 只需处理拆股 | 必须处理**除权除息**（送股、转增、配股、分红）。A 股数据源通常直接提供前复权/后复权序列——**优先用数据源的复权价**，不要用第 3 节的启发式判定。若只能拿到不复权价，第 3 节的比例表要换成 A 股的送转比例，且**分红除息的缺口远小于 35%，这套启发式抓不到**，会造成系统性偏差 |
| **基准** | SPY | 大盘用沪深300（或中证800）；行业基准用**申万一级行业指数**或对应行业 ETF。行业分类必须和榜单展示用的分类一致 |
| **成交额门槛** | 2000 万美元 | 换成人民币并按 A 股流动性分布重新定标。**不要简单按汇率换算**——应取全市场成交额分布的某个分位（例如剔除后 30%），让门槛随市场自适应 |
| **涨跌停** | 无 | 主板 ±10%、创业板/科创板 ±20%、ST ±5%。**一字板会同时污染两个榜**：涨停板当日残差 z 被人为截断（真实意外被压缩），而连续一字板期间成交量极低会让 `volume_z` 条件失效。建议：异动榜对**涨跌停封板**（成交量异常低 + 收盘价贴在涨跌停价）单独打标签并**排除出排序**，或作为独立事件类型 |
| **停牌** | 罕见 | 常见且可能持续数月。复牌首日的收益率跨越了整个停牌期，`residual_z` 会爆表但毫无信息。**必须按交易日而非自然日构造序列，并对停牌超过 N 日的复牌首日跳过或单列** |
| **T+1** | 无 | 影响「可交易性」的判断，但不影响筛选公式本身。若机会挖掘模块要给操作建议，需要考虑当日不能卖出 |
| **新股 / 次新股** | — | 上市不足 210 日直接不进强趋势榜（本口径的 `min_history_days` 已自动排除）；异动榜的 180 日门槛同理。**不要为了让次新股进榜而放宽这两个数**——beta 和残差 sigma 估不准，出来的 z 分数是假的 |

### 4.2 可以直接照搬的

- 闸门/排序分离的结构
- 四因子横截面百分位加权（权重可以按 A 股重新拟合，但**先用 0.35/0.35/0.20/0.10 跑一遍作基线**）
- 「前 20% 是个数不是阈值」的切点实现，含代码作为第二排序键
- beta 残差 z 的全部公式与 `ddof` 细节
- 严重度只由幅度决定、触发器个数不参与升级
- 排序键必须等于榜上打印的数字
- 板块共振只作上下文
- 未过闸门记 NULL 不记 0

### 4.3 建议照搬的工程约束

这几条不是口径，是让口径不出事的护栏，代价很小：

1. **基准陈旧/不可用 → 整个扫描跳过，不降级。** 降级出来的榜是「错数字挂对标签」。
2. **数值边界必须有 sanity constraint**：分母为零、方差为零、sigma 为零，一律跳过并计入 skip 原因，不返回默认值。
3. **区分「成功跑完但没有结果」和「跑失败了」。** 空榜必须能说清是「今天确实没有」还是「没算出来」——两者在读者眼里长得一模一样，而含义完全相反。
4. **旧格式数据要有守卫**。本次改造把新字段加进表里，旧行的新字段为 NULL；缺守卫时旧行会被渲染成 `超额+0% 0天 0.0ATR` 一整屏——**「接在空线上的绿灯」**。加上 `字段 IS NOT NULL` 过滤后，退化为诚实的「暂无」。

## 5. 参数速查

```yaml
# 强趋势
benchmark: SPY
min_history_days: 210
gate:
  require_ma_stack: true          # close > MA20 > MA50 > MA200
  ma200_rising_lookback: 20
  require_positive_dmi: true      # +DI > -DI
  dollar_volume_20d_min: 20000000
score_weights:                    # 作用在闸门内横截面百分位上
  rel_126d: 0.35
  rel_63d: 0.35
  path_quality: 0.20
  pct_of_high: 0.10
strong_top_pct: 0.20              # ceil(n × 0.20)，代码作第二排序键
breakdown_lookback_days: 60
high_lookback: 252                # pct_of_high 的窗口

# 异动
fallback_benchmark: SPY           # 无行业 ETF 时
min_history_days: 180
history_window: 252               # beta / sigma 估计窗口，不含当日
```
